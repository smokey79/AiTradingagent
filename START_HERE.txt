## 🔧 Troubleshooting

→ Check `F:\aitradingagent\logs\launcher_*.log`

### Python/Node not installed?
→ Install from python.org / nodejs.org

### Port already in use?
→ Wait 30s after last run or kill node.exe

### Shortcut missing?
→ Run `CREATE_DESKTOP_SHORTCUT.ps1` again
