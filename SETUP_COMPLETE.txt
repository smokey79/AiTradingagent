## 🔧 IF SOMETHING GOES WRONG

### Check Logs First
```
F:\aitradingagent\logs\launcher_*.log
```

Look for error messages related to:
- Python/Node not installed
- Dependency failures
- Port conflicts

### Re-create Shortcut
```powershell
cd F:\aitradingagent
powershell -ExecutionPolicy Bypass -File CREATE_DESKTOP_SHORTCUT.ps1
```

### Run Launcher Manually
```cmd
F:\aitradingagent\launch-full-stack.bat
```

### Kill All Processes
```cmd
taskkill /F /IM node.exe /IM python.exe
```
