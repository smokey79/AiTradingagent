# AiTradingAgent Desktop Launcher — Quick Reference

## 🚀 LAUNCH THE STACK

**Double-click this shortcut on your desktop:**
```
AiTradingAgent.lnk
```

**Location:** `C:\Users\barcl\OneDrive\Desktop\AiTradingAgent.lnk`

| Service | URL | Purpose |
|---------|-----|---------|
| **Dashboard** | http://localhost:3000 | Real-time P&L, trades, metrics |
| **Backtester** | http://localhost:3001 | Test strategies & optimize |
| **Monitor** | http://localhost:3002 | View logs & system health |

## 🔧 TROUBLESHOOTING

| Problem | Fix |
|---------|-----|
| Services won't start | Check `logs/launcher_*.log` |
| Port 3000 in use | Close dashboard or restart |
| Python/Node not found | Install from python.org / nodejs.org |
| Shortcut missing | Run `CREATE_DESKTOP_SHORTCUT.ps1` |

## 🔑 QUICK COMMANDS

### Manual Launch (if shortcut fails)
```cmd
F:\aitradingagent\launch-full-stack.bat
```

### Create Shortcut Again
```powershell
cd F:\aitradingagent
powershell -ExecutionPolicy Bypass -File CREATE_DESKTOP_SHORTCUT.ps1
```

### View Recent Logs
```cmd
cd F:\aitradingagent\logs
dir /o-d
```

### Kill All Processes
```cmd
taskkill /F /IM node.exe /IM python.exe
```
